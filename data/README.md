# Data in this repository

## Included

| Path | What it is | Licence / terms |
|---|---|---|
| `synthetic/*.csv` | Per-organism growth-rate datasets generated by `src/datasets.py` from **illustrative** cardinal parameters (plus noise). Demonstration data, not measurements. | MIT (this project) |
| `kinetic_curve_sample.csv`, `cold_chain_sample.csv` | Small synthetic examples used by the app and the tests. Regenerate with `scripts/generate_sample_data.py`. | MIT |
| `external/` | Growth rates transcribed from a published study, with a full provenance record (`external_sources.csv`), the rows deliberately excluded and why (`external_excluded_rows.csv`). | CC BY 4.0, attribution in `external/ATTRIBUTION.md`. The authors did not endorse the transcription or the unit conversion. |

## Deliberately NOT included

**ComBase-derived data.** The real growth-rate and kinetic-curve datasets used in the project's published results
were extracted from ComBase Browser exports. ComBase's terms grant its users a non-transferable licence and
redistribution of exports and derived datasets has not been cleared, so none of it is distributed here.
The loaders, cleaning code, validation scripts and result tables are all included; only the data is not.

**Runtime state.** The accounts and saved-runs database (`analysis_ledger.sqlite3`), the model cache
(`trained_models/`) and pretrained models (`pretrained_models/`) are created locally and git-ignored.

## Building the optional real-data bundle yourself

You need your own ComBase access and the right to use the exports.

```bash
# 1. Export records from the ComBase Browser (.xlsx files) into a folder, then:
python scripts/build_real_datasets.py /path/to/your/combase_exports
#    writes data/combase_growth_dataset.csv, combase_kinetic_curves.csv, combase_dynamic_profiles.csv, combase_load_report.csv

# 2. Optional: set aside records that contradict the rest of their organism's data
python scripts/flag_suspect_records.py            # writes data/suspect_records.csv

# 3. Rebuild the models for the new data
python scripts/pretrain_models.py --jobs 4
```

These files are git-ignored (see `.gitignore`), so they cannot be committed by accident. Once present, the app
lists "(installed real)" datasets automatically and the tests that depend on them run instead of being skipped.
The optional `data/expanded/` bundle (real plus synthetic observations with train / validation / test splits) is built
by `scripts/build_clean_and_synthetic.py` from your own cleaned observations.

If you obtain written permission from the ComBase owners to redistribute a derived dataset, keep that letter with
the data and record it in `external/external_sources.csv` before bundling anything.
